# Williams Records — Official Website

A modern, responsive multi-page website for **Williams Records**, a creative media studio offering music recording, photography, videography, and live event production services.

Built with clean HTML, CSS, and vanilla JavaScript — no frameworks, no build step, no dependencies beyond CDN-hosted Font Awesome.

## 🎯 Overview

Williams Records is a full-service creative studio based in Nairobi, Kenya, offering:

- **Music recording & production**
- **Audio mixing & mastering**
- **Professional photography**
- **Video production & editing**
- **Wedding filming**
- **Live event coverage**

This website serves as the studio's digital storefront — showcasing services, portfolio work, the team, and providing an easy way for clients to get in touch and book sessions.

## ✨ Features

- 🎨 **Modern orange & gold design** — consistent brand identity across all pages
- 🌗 **Dark mode toggle** — user preference saved with `localStorage`
- 📱 **Fully responsive** — mobile-first layout with a slide-in navigation menu
- 🎬 **Animated hero sections** — floating music notes and smooth fades
- 🖼️ **Filterable gallery** — filter by photos, videos, or live recordings with a lightbox viewer
- 👥 **Filterable team grid** — sort team members by department
- 📅 **Booking form** — with date/time picker, service selection, and Formspree integration
- 📊 **Animated statistics** — scroll-triggered counters and reveals
- ⏱️ **Booking prompt modal** — appears after inactivity to encourage engagement
- 🚀 **Zero build tools** — pure HTML/CSS/JS, ready to deploy anywhere

## 🛠 Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties (CSS variables), grid, flexbox, animations
- **Vanilla JavaScript** — no frameworks
- **Font Awesome 6.4** — icons (via CDN)
- **Google Fonts (Poppins)** — typography
- **Formspree** — contact form handling

No build step. No npm. No bundler. Just open `index.html` in a browser.
